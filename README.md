# a little note for you — plain HTML/CSS/JS

This version preserves the wording, memory cards, reasons, letter reveal, and ending interaction from the React source you shared, but uses plain HTML, CSS, and JavaScript.

## Photos
Copy your existing `p1.jpg`, `p2.jpg`, and `p3.jpg` into the `images` folder beside `index.html`.

Expected structure:
```
apology/
├── index.html
├── styles.css
├── script.js
└── images/
    ├── p1.jpg
    ├── p2.jpg
    └── p3.jpg
```

Open `index.html` to test locally. For GitHub Pages, upload these files to the repository root and set **Settings → Pages → Deploy from a branch → main → /(root)**.
